# 💎 Sapphire Programming Language — Debian & Kali Linux Distribution Folder

This folder contains everything needed to install Sapphire and Emerald Developer Studio on **Debian**, **Kali Linux**, **Ubuntu**, **Linux Mint**, and **Debian-derived Linux distros**.

---

## 📦 3 Ways to Install on Debian / Kali Linux

### Method 1: Graphical Setup Wizard (GUI)
Double-click or run the wizard script:
```bash
chmod +x install_wizard.sh
./install_wizard.sh
```

---

### Method 2: Native `.deb` Package (`sudo apt install`)
Install via APT / dpkg package manager:
```bash
sudo apt install ./nexus_1.0.0_all.deb
```

---

### Method 3: 1-Line Universal Terminal Command
Install from anywhere via curl:
```bash
curl -sSL https://raw.githubusercontent.com/impala19067-hub/Nexus-autonomous-language/main/install.sh | bash
```
